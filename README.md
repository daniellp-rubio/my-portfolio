# 🚀 My Portfolio

Portafolio profesional enfocado en demostrar valor real, no solo habilidades técnicas.

Diseñado para comunicar impacto, generar confianza rápida y convertir visitas en oportunidades laborales o clientes.

---

## 🧠 Enfoque

Este no es el típico portafolio de desarrollador.

Está construido con una mentalidad clara:

* Mostrar resultados, no solo código
* Priorizar claridad y conversión
* Diferenciarse del 90% de desarrolladores

---

## ⚡ Tech Stack

* **Framework:** Next.js 14 (App Router)
* **Lenguaje:** TypeScript
* **Estilos:** Tailwind CSS
* **Deploy:** Vercel
* **Optimización:** SEO + Performance (Lighthouse 90+)

---

## 📁 Estructura del proyecto

```
my-portfolio/
│
├── app/                # Routing y layout principal
├── components/         # Componentes reutilizables
│   ├── ui/             # Componentes base
│   └── sections/       # Secciones del portafolio
├── lib/                # Utilidades
├── public/             # Assets
```

---

## 🧩 Secciones principales

* **Hero:** Propuesta de valor clara en menos de 5 segundos
* **Projects:** Casos reales enfocados en problema → solución → resultado
* **About:** Posicionamiento estratégico (no historia genérica)
* **Contact:** Llamado a la acción directo

---

## 🎯 Objetivo

Este portafolio está optimizado para:

* Conseguir oportunidades laborales remotas
* Atraer clientes freelance
* Demostrar capacidad real de resolver problemas

---

## 🔍 Optimización

* SEO estructurado (metadata, Open Graph)
* Performance optimizada
* Diseño responsive
* Base lista para accesibilidad

---

## 🚀 Deploy

El proyecto está preparado para desplegarse fácilmente en Vercel:

```bash
npm install
npm run dev
```
